**Lexicon Version:** 1

## Definitions

<a name="main"></a>

### `main`

**Type:** `query`

Fetch a content-addressed MUXL playback blob by CID. Serves either a primary fMP4 archive or a per-track init segment — both are CID-addressed and indistinguishable from the endpoint's point of view. HTTP `Range` headers are honored; HLS media playlists generated by getVideoPlaylist reference this endpoint with `EXT-X-BYTERANGE` to serve segments out of the primary blob.

**Parameters:**

| Name  | Type     | Req'd | Description                              | Constraints |
| ----- | -------- | ----- | ---------------------------------------- | ----------- |
| `cid` | `string` | ✅    | BLAKE-3 BDASL CID of the requested blob. |             |

**Output:**

- **Encoding:** `video/mp4`
- **Schema:**

_Schema not defined._
**Possible Errors:**

- `BlobNotFound`: This node doesn't have the requested CID. The caller should consult place.stream.media.origin records to find a node that does.
