---

Streamplace lets you attach an activity and tags to your livestream. These can help viewers find and understand your content.

## Activities

An activity describes what you're streaming. There are two kinds:

- Games: Selected from the [Cartridge.dev](https://cartridge.dev) database via search
- Other activities: Chosen from a preset list.

You can pick one activity per stream. When you create or edit a livestream, the activity picker shows two tabs: "Game" and "Other Activity". Searching in the Game tab queries the catalog, and the Other Activity tab shows the preset labels as selectable pills.

If we don't have an activity that you expect, feel free to [file an issue](https://github.com/streamplace/streamplace/issues/new), and we'll be happy to review and add it.

## Tags

Tags are freeform labels you can add to your stream. Some rules:

- Alphanumeric characters only (a-z, A-Z, 0-9)
- Up to 10 tags per stream
- Be courteous towards others and follow the community guidelines when picking tags

### Language tags

The live dashboard has a language picker that manages language tags for you.

If we don't have your language, please [file an issue](https://github.com/streamplace/streamplace/issues/new) and we'll be happy to review and add it.

Note that when viewing a stream, language tags display as their native name and not the language code.
